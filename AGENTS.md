# Project Tracker — Agent Instructions

> Read `CLAUDE.md` first.

- Treat this as a persistent dev-server-only tool.
- Use `npm run dev`, reuse an existing server, and leave it running.
- Never run or require a production build.
- Do not add a production adapter.
- Verify changes with source checks and the running dev server.
- Do not modify any discovered project while working on the tracker.
